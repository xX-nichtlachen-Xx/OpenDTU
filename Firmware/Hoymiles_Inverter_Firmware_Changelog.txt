Hoymiles Inverter DSP Firmware — Change Log
================================================================================
Scope: HM (1T/2T/4T), HMS (1T/2T/4T), HMT (6T).

HM-1T   V01.00.17 -> V01.01.00
  Added:
    - Control loop soft-foldback limiter (scales input down ~0.1x on overshoot).
    - Grid-frequency in-band debounce counter.
    - Explicit power-limit COMMIT sub-mode (0x40) in the 0x51 control path.
  Changed:
    - ePWM output config now runtime-switchable between two modes (was fixed).
    - 0x51 reply builders refactored.
    - RF re-join / backoff scheduling reworked.
  Removed:
    - Alarm-history read dropped its secondary latched/priority alarm table
      (now scans only the live event ring).
    - Hidden 0x30 / 0xFF selector no longer returns values over the NRF radio
      (confirmed on hardware): the command still parses, but its value-reply path was
      reworked so it emits nothing; the request now only drives internal actions.
